### 标签
动态规划，模板题

### 思路
$dp[i]$ 代表背包容量为 $i$ 时装的最大价值。
分组后对每个组进行转移，转移前拷贝 $ndp=dp$，这样保证每个组只取一个物品。
对于一个大小 $w$ 价值 $v$ 的物品，转移方程有
$$ndp[j]=max(ndp[j], dp[j-w]+v),(j\in[w,M])$$
由于 $dp$ 中没有该物品，不会重复取，可以正序循环。

### 时间
$O(nM)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
void solve()
{
    int n, W;
    cin >> n >> W;
    vector<vector<pair<int, int> > >a(105);
    for (int i = 0, w, v, g; i < n; i++)
    {
        cin >> w >> v >> g;
        a[g].push_back({w, v});
    }
    vector<ll>dp(W + 1);
    for (int i = 1; i <= 100; i++)
    {
        auto ndp = dp;
        for (auto [w, v] : a[i])
        {
            for (int j = w; j <= W; j++)
            {
                ndp[j] = max(ndp[j], dp[j-w] + v);
            }
        }
        dp = ndp;
    }
    cout << dp[W];
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t = 1;
    //cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
