#### 思路
第一种情况： $k$ 是最高层，此时答案为 $k-1$。
第二种情况： $k$ 不是最高层，此时电梯先到最高层再往下到 $k$ 层。
先记录最高层 $mx$，$mx-1+mx-k$ 符合两种情况，即先到其他人的最高层后再到 $k$ 层。

#### 时间
$O(n)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
void solve()
{
    int n, k, mx = 0;
    cin >> n >> k;
    for (int i = 0, x; i < n; i++)
    {
        cin >> x;
        mx = max(mx, x);
    }
    cout << mx - 1 + mx - k;
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t = 1;
    //cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
