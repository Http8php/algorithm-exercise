#### 标签：
组合数学

#### 思路：
考虑化简 $\sum_{i=0}^{n-1}{i^2\times a[i]}$ 这个式子。

根据杨辉三角的定义： $a_i=\binom{n-1}{i}$

令 $N=n-1$，得到 $\sum_{i=0}^{N}{i^2\times \binom{N}{i}}$

由于 $i^2=i\times (i-1)+i$

原式 $=\sum_{i=0}^{N}{i(i-1) \binom{N}{i}}+\sum_{i=0}^{N}{i\binom{N}{i}}$

$\binom{N}{i}=\frac{N!}{i!(N-i)!}$

两边同乘 $i$， $i\binom{N}{i}=\frac{N!}{(i-1)!(N-i)!}=N\binom{N-1}{i-1}$

$\sum_{i=1}^{N}{N\binom{N-1}{i-1}}=N\sum_{i=1}^{N}{\binom{N-1}{i-1}}$，$i=0$ 时不影响和，可以随意改。

$\sum_{i=1}^{N}{\binom{N-1}{i-1}}=2^{N-1}$，所以 $\sum_{i=0}^{N}{i\binom{N}{i}}=N\times 2^{N-1}$

同理， $\sum_{i=0}^{N}{i(i-1) \binom{N}{i}}=N(N-1)\times 2^{N-2}$

$N\times 2^{N-1}+N(N-1)\times 2^{N-2}$
$=N\times 2^{N-2}(2+N-1)$
$=N(N+1)2^{N-2}$

把 $N=n-1$ 代回，得到 $n(n-1)2^{n-3}$

用快速幂计算 $2^{n-3}$，对 $n,n-1$ 取模后相乘，防止爆 $ll$。

注意模数不是正常的 $998244353$。

#### 时间：
$O(logn)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int mod = 99824353;
ll fp(ll a, ll b)
{
    a %= mod;
    ll ans = 1;
    while (b > 0)
    {
        if (b & 1) ans = ans * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return ans;
}
void solve()
{
    ll n;
    cin >> n;
    if (n == 2)
    {
        cout << 1;
        return;
    }
    cout << fp(2, n - 3) * (n % mod) % mod * ((n - 1) % mod) % mod;
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t = 1;
    //cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
