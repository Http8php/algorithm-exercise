### 思路
递增的全排列会产生 $n$ 个环，而每次交换可以多一个环。

所以答案就是需要增加的环，即 $n-m$。

### 时间
$O(1)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
void solve()
{
    ll n, m;
    cin >> n >> m;
    cout << n - m;
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t = 1;
    //cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
