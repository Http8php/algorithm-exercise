### 标签
构造、贪心

### 思路
当 $y$ 的个数 $cnt_y\ge2$ 时，后面每出现一个 $c$ 就会产生 $\binom{cnt_y}{2}$ 的贡献。

于是可以贪心地摆，$cnt_y$ 从大到小遍历，如果 $x=\binom{cnt_y}{2}\ge n$，说明后面需要放 $\lfloor\frac{n}{x}\rfloor$ 个 $c$， $n$ 变成 $n\% x$，由于最后 $x=1$，所以 $n$ 一定可以变成 $0$。

$\binom{44721}{2}\ge 10^9$，构造出的字符串最长为 $44721 \times 2 \le 10^5$。

### 时间
预处理: $O(N)$ 
单组: $O(N)$ 其中 $N=45000$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int N = 45000;
ll x[N+1];
void init()
{
    for (ll i = 2; i <= N; i++)
    {
        x[i] = i * (i - 1) / 2;
    }
}
void solve()
{
    int n;
    cin >> n;
    vector<ll>cnt(N + 1);
    for (ll i = N; i >= 2; i--)
    {
        cnt[i] += n / x[i];
        n %= x[i];
    }
    string ans;
    for (int i = 1; i <= N; i++)
    {
        ans += 'y';
        ans += string(cnt[i], 'c');
    }
    cout << ans.size() << '\n';
    cout << ans << '\n';
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    init();
    int t = 1;
    cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
