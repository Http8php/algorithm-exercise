#### 标签
计算几何，枚举

#### 思路
从 $x=x_0$ 切割，由于数据量不大，可以直接枚举。
题目中给出的三角形一定是锐角或直角，所以切割后一定有一半是三角形，如果 $x_0\le x_c$，三角形在左边， $x_0>x_c$，三角形在右边。
枚举时，只要判断这个三角形的面积是否是原图形的一半， $S_原=\frac{1}{2}x_{b}y_{c}$ 计算。
对于左边的三角形，底是 $x_0$，高 $h$ 可以用相似三角形求，即 $\frac{h}{y_c}=\frac{x_0}{x_c}$，化简条件得 $2x_0^2=x_bx_c$，右边同理可得 $2(x_b-x_0)^2=x_b^2-x_bx_c$。


#### 单组时间
$O(x_b)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
void solve()
{
    int xb, xc, yc;
    cin >> xb >> xc >> yc;
    for (int i = 0; i <= xb; i++)
    {
        if (i <= xc && 2 * i * i == xc * xb)
        {
            cout << "YES\n";
            return;
        }
        if (i > xc && 2 * (xb - i) * (xb - i) == xb * xb - xb * xc)
        {
            cout << "YES\n";
            return;
        }
    }
    cout << "NO\n";
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t = 1;
    cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
