### 思路
如果给出的 $n$ 是 $495$ 的倍数，直接输出 $-1$。

剩下的情况，要在后面填数，设填入的数为 $x$， $n$ 就变为 $n10^k+x$， $k$ 是 $x$ 的位数。

这个数要是 $495$ 的倍数，必须符合 $n10^k+x\equiv 0\pmod{495}$，即 $x\equiv-n10^k\pmod{495}$，只要求 $-n10^k$ 的余数就能求出 $x$ 的值。

设余数为 $r$，由于 $mod=495$， $0\le r<495$，同时 $0\le x<10^k$，所以所以只要 $r<10^k$，就能直接取 $x=r$，用前导零补成 $k$ 位即可成功。 $k=3$ 时 $10^k=1000>495$，所以 $k=3$ 时一定有答案，不用检查更大的 $k$。

### 时间
$O(1)$

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
void solve()
{
    ll n;
    cin >> n;
    n %= 495;
    if (n == 0)
    {
        cout << -1;
        return;
    }
    int p = 1;
    for (int k = 0; k < 3; k++)
    {
        p *= 10;
        int r = (-n * p % 495 + 495) % 495;
        if (r < p)
        {
            string s = to_string(r);
            int len = s.length();
            if (len < k + 1)
            {
                int d = k + 1 - len;
                s = string(d, '0') + s;
            }
            cout << s;
            return;
        }
    }
}
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t = 1;
    //cin >> t;
    while (t--)
    {
        solve();
    }
    return 0;
}
```
